# Quant Toolbox

Typed, numpy-first performance, risk, research, and report code for investment teams. Every convention is
stated, every undefined number is NaN rather than a guess, and only numpy is required.

It is the library under [Quant-Agent-OS](https://github.com/yuxuzi/quant-agent-os)'s analytics tools and
under every application its App Factory generates, and it stands on its own: it imports nothing of the
platform. MIT licensed.

```bash
uv add "quant-toolbox @ git+https://github.com/yuxuzi/quant-agent-os@v0.6.0#subdirectory=packages/quant-toolbox"
```

See the [product page](https://github.com/yuxuzi/quant-agent-os/blob/main/docs/products/quant-toolbox.md)
for what it holds, and [CHANGELOG.md](CHANGELOG.md) for what changed.
