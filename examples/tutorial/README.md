# Tutorial files

The files [docs/tutorial.md](../../docs/tutorial.md) uses. All the data is synthetic.

| File | Used in | What it is |
| --- | --- | --- |
| `env.sh` | Setup | Tutorial settings; everything goes in `~/qaos-tutorial` |
| `data/fund_returns.csv` | Lab 2 | 36 months of a fund and its benchmark |
| `data/portfolio_returns.csv` | Lab 2 | 36 months of three assets and two factors |
| `lab_analytics.py` | Lab 2 | Performance and risk metrics by dataset id |
| `data/notes/my-reversal-note.md` | Lab 3 | A note to add to the knowledge store |
| `lab_first_tool.py` | Lab 4 | Write, check, and call your own tool |
| `lab_guardrails.py` | Lab 5 | Refusals, and the approval flow |
| `show.py` | Lab 7 | Prints REST responses as a few readable lines |
